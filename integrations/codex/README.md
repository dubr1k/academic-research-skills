# Codex: короткие навыки, полные методики

Адаптация поддерживается в форке `dubr1k/academic-research-skills`. Она переносит
локальные улучшения загрузки в воспроизводимую сборку: девять коротких навыков EN/RU,
отдельные инструкции исполнения Codex и полный снимок методик из текущего **коммита**.
Исходные научные инструкции, лицензии, ресурсы и адаптации других платформ не меняются.

Применён принцип [постепенного раскрытия инструкций OpenAI](https://developers.openai.com/codex/skills/):
название и описание используются для выбора навыка, подробные методики читаются
по необходимости. Это уменьшает объём входного файла навыка; экономия токенов
в реальном научном цикле не измерена.

## Сборка и подключение

Требуются Git и Python 3.9+. Из корня проверенного клона:

```bash
python3 integrations/codex/build.py \
  --destination "$HOME/.codex/skill-bundles/academic-codex-v1" \
  --explicit-pipelines
```

Путь должен быть новым и находиться вне исходного клона. Не помещайте весь пакет
в каталог автоматического поиска навыков: `source/` содержит исходные SKILL.md.
Сборка не вызывает сеть, не меняет конфигурацию, hooks или существующие навыки.
Незафиксированные изменения методик не включаются; адаптер берётся из рабочей копии,
а хеши его файлов сохраняются в `MANIFEST.json` вместе с коммитом и хешами ресурсов.

Подключите только нужные подкаталоги `skills/<name>` через интерфейс Codex либо
скопируйте их в используемый вами пользовательский каталог навыков. Перед заменой
сохраните старые каталоги отдельно; не устанавливайте второй экземпляр того же имени
через плагин или другой путь. Две версии полного конвейера становятся доступными
только по явному вызову **при указании** `--explicit-pipelines`; без флага сохраняется
стандартное поведение Codex. `sr-screener` предназначен для явно запрошенного отбора
предоставленных исследований, а не для обычного обзора литературы.

После подключения начните новый сеанс и проверьте обнаруженные пути навыков.
Ссылки на снимок генерируются для выбранного абсолютного пути. При переносе на другую
машину или в другой каталог повторите сборку; исходный Git-клон после неё не нужен.
Для обновления соберите новый каталог и переключите нужные навыки после проверки.
Для отката восстановите сохранённые каталоги навыков; прежний пакет не удаляется.

Русские входные файлы ссылаются на общий справочник контекста из того же снимка.
Его читают по нужному разделу: русский язык не подменяет страну, юрисдикцию,
требования учреждения или заданный APA/IEEE. Английские входные файлы не получают
дополнительных русских инструкций.

## Границы исполнения

`RUNTIME.md` переводит платформенные вызовы Claude/OpenCode в реально доступные
инструменты Codex, сохраняет выбор режима, ограничения источников, проверки целостности,
изоляцию рецензентов и чтение проектного `CLAUDE.md`. Полный научный процесс не становится
проверенным от одной установки. Не предполагается наличие Claude hooks или библиотек
для всех научных утилит: зависимости проверяются перед запуском соответствующего режима.

## Проверка

```bash
python3 -m unittest discover -s integrations/codex -p 'test_*.py' -v
```

Тесты проверяют сохранность байтов и исполняемых прав исходников, девять коротких
входных файлов, ссылки при пробелах в пути, хеши, явный выбор конвейеров и отказ
от перезаписи или записи через символические ссылки. Это проверки упаковки и
контрактов. Полный научный конвейер в Codex и качество независимой рецензии здесь
не измерены. Исполнение не закрепляет конкретную модель: используются настройки сеанса.
